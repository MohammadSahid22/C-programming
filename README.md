# 📚 Overview

This repository contains **basic C programming examples** for beginners to understand:

* Conditional statements
* Loops
* Functions
* Arrays
* Mathematical algorithms
* Number-based problems

These programs are useful for **students learning C programming** and preparing for **lab assignments or exams**.

# ⚙️ How to Run Programs

### 1️⃣ Compile the program

```bash
gcc filename.c
```

Example:

```bash
gcc factorial.c
```

---

### 2️⃣ Run the program

```bash
./a.out
```

# 🧪 Example Program

```c
#include <stdio.h>

int main() {
    int a = 5, b = 10;
    printf("Sum = %d", a + b);
    return 0;
}
```

Output

```
Sum = 15
```
